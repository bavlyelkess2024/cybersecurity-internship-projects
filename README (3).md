# Cyber Security Internship Projects

Hands-on security labs and a security architecture project completed during the Progree Cyber Security internship.
All testing is performed only in an isolated lab on machines I own.

## Projects

| Project | Description |
|---------|-------------|
| [Threat Modeling & Incident Response Blueprint](threat-modeling-ir-blueprint) | STRIDE threat model, Zero-Trust access policy with MFA, 4-stage incident response plan, ransomware and database-breach playbooks |
| [Vulnerability Assessment Lab](vuln-assessment-lab) | Lab setup, Nmap/Nikto scanning workflow, CVE/CVSS triage methodology |
| [Packet Analysis with Wireshark](packet-analysis-wireshark) | Capture workflow, display filters, TCP handshake and clear-text protocol analysis |

## Tools & frameworks
Nmap, Nessus, Nikto, Wireshark, STRIDE, Zero Trust (NIST SP 800-207), NIST SP 800-61, MITRE ATT&CK, CVE/CVSS.

## Ethics
Only scan or capture traffic on systems you own or are explicitly authorized to test.
